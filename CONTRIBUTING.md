# Contributing

- Create work from an issue with an explicit scope.
- Do not commit provider keys, raw licensed data, or production model bundles.
- Add tests for every normalization, calibration, and publication change.
- Preserve integer-line push handling.
- Preserve fail-closed publication behavior.
- Preserve current-cycle-only public snapshots.
- Document any schema or terminology change.
- Require chronological out-of-sample evidence for model changes.
